ETL (Extract, Load, Transform)

Tópico 1

Introdução

Como já vimos, ETL é um processo fundamental para a integração de dados. Ele envolve a extração de dados de diversas fontes, tanto estruturadas (como bancos de dados relacionais) quanto não estruturadas (como arquivos de texto e dados de redes sociais). Em seguida, esses dados são carregados em um sistema de armazenamento, como um data lake, para então passarem pelas transformações necessárias — como limpeza, formatação e agregação —, garantindo que fiquem prontos para análise. Dessa forma, os dados tornam-se acessíveis e realmente úteis para apoiar a tomada de decisão e análises mais aprofundadas. A figura a seguir ilustra o processo de ETL.

Então, por que o profissional do SUS precisa entender ETL?

No dia a dia do SUS você trabalha com dados que vêm de diferentes sistemas: SINAN, SIM, SINASC, SIH, SIA, e-SUS AB, entre outros. Cada sistema tem seu próprio forma-to, suas próprias variáveis, e frequentemente os dados precisam ser combinados para gerar análises epidemiológicas ou relatórios de gestão.

O processo de ETL é exatamente o que você faz (muitas vezes manualmente no Excel) quando precisa:

  • Baixar dados de diferentes sis-temas.
  • Limpar inconsistências e valores faltantes.
  • Padronizar códigos de municí-pios ou CIDs.
  • Juntar bases para análise.
  • Salvar em formato adequado para relatórios.

A diferença é que, com as ferramentas certas, você pode automatizar esse processo e trabalhar com milhões de registros em vez de alguns milhares de linhas.
